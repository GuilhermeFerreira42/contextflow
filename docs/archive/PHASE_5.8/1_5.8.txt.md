# Documentação de Restauração: Aba 1 (Doca de Carga) - Padrão 5.6


Esta documentação detalha os requisitos para reverter a interface e as funções da **Aba 1 (`ui/tab_batch.py`)** para o estado de alta produtividade da Fase 5.6, mantendo o isolamento físico exigido pela Fase 5.7.


## 1. Visão Geral da Interface


A interface deve seguir o layout de **painéis fixos verticais**, sem divisores móveis (splitters), garantindo a estabilidade visual durante o processamento de grandes lotes de URLs.


### Estrutura de Topo: Painel de Ingestão


* **Título do Painel:** "Adicionar URLs".


* **Campo de Texto:** `wx.TextCtrl` multiline para colagem massiva de links.


* **Botão 1: 🧹 Limpar:** Esvazia o campo de texto de entrada.


* **Botão 2: ▶️ Processar Fila:** Envia os links para o `Processor` e inicia a extração.


## 2. Configuração da Grade de Dados (Grid Virtual)


A grade deve ser alimentada pela `VirtualVideoTable` para suportar até 10.000 itens sem perda de performance.


### Colunas Mandatórias (Ordem de Exibição):


Conforme solicitado, a grade deve conter as seguintes colunas:


1. **# (Índice):** Numeração automática das linhas para referência rápida.


2. **[x] (Seleção):** Checkbox para seleção de múltiplos vídeos para ações em massa.


3. **Miniatura (Thumbnail):** Visualização da imagem do vídeo (ícone ou preview).


4. **Título:** Nome do vídeo extraído do YouTube.


5. **Canal:** Nome do autor ou canal do vídeo.


6. **Publicado:** Data de upload original do vídeo.


7. **Adicional (Adicionado):** Data e hora em que o vídeo foi inserido no sistema.


8. **Playlist:** Título da playlist de origem (se houver).


9. **Duração:** Tempo total do vídeo formatado (HH:MM:SS).


10. **Contagem de Tokens:** Total de tokens calculados da transcrição.


11. **Estatísticas (Status):** Estado atual (Pendente, Processando, Concluído ou Erro).


## 3. Botões de Ação (Rodapé)


Localizados na base da tela, estes botões operam sobre os vídeos marcados na coluna de seleção:


* **🗑️ Excluir:** Remove os vídeos selecionados da memória, do banco de dados e apaga os arquivos de miniatura associados.


* **🔗 Unificar (.md):** Consolida as transcrições de todos os vídeos selecionados em um único arquivo Markdown para facilitar a leitura contínua.


* **📄 Baixar como MD:** Gera arquivos Markdown individuais para cada vídeo selecionado, contendo metadados e transcrição.


* **📦 Exportar (ZIP):** Compacta as exportações em um arquivo ZIP organizado.


## 4. Funcionamento Técnico (Regras de 5.6)


* **Reatividade via PubSub:** A tela deve "acordar" e atualizar a linha correspondente sempre que receber um sinal de `TASK_PROGRESS` ou `TASK_COMPLETED`.


* **Indicação de Erros:** Vídeos com falha (ex: erro 429 de limite de taxa) devem destacar a coluna de Status em **vermelho** para triagem visual imediata.


* **Log de Sistema:** O **System Log** deve estar presente na base da janela principal (integrado via `app_window.py`) para exibir o histórico de mensagens técnicas durante o uso desta aba.
